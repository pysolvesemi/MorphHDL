# WA-08 production named-alias repair

This repairs the completed WA-08 production handoff on top of
`39d888874577dc989f43e602c577985ebc53bc69`. It does not introduce another pass or
roadmap increment. The default-on configuration and `enabled = false` opt-out
are unchanged.

## Defect and discovery fix

`NamedWireAliasNativePhase` previously required
`ExplicitNamedWireAliasSourceTag`, which existed only in the shared FIFO
fixture. Ordinary production aliases could not enter the native safety proof.

The adapter now reads retained `Nameable` naming metadata before name
propagation/allocation. It accepts the existing user/reflected priority
categories and rejects generated/removable or unknown categories. The retained
source name enters the existing canonical named-alias decision; it is never a
selection pattern and is not transferred to another signal. The FIFO witness
also uses genuine naming metadata and no longer supplies the obsolete tag.

## Eligibility remains bounded

- The alias is an internal root-scope combinational object with one full-object
  direct assignment. Ports, registers, type nodes, partial or conditional
  assignments, and named expression wires are not eligible.
- The source must be in the same component and root scope. A direct input-port
  source whose native scope differs is retained, as before.
- Every receiver must be a local root-scope continuous assignment. Procedural,
  state, hierarchy and other non-expression uses remain protected. The
  receiver must have one full-object assignment: a root default feeding a
  multiply assigned procedural destination is not a continuous receiver.
- Width, packed kind and signedness must agree. Symbolic widths still require
  the same retained expression identity; equal defaults or independently built
  equal-looking expressions are insufficient.
- Preservation/debug tags, frozen declarations, `dontSimplify` and assignment
  trace comments prevent removal. Clock, reset, soft reset, clock-enable and
  pulled control identities are protected outside the expression-use graph.
- References from native timing/debug/initialization metadata also prevent
  removal. Unknown metadata tags fail closed because their complete reference
  inventory is unavailable.
  Such metadata can conservatively retain otherwise eligible aliases.
- The existing cycle and canonical decision gates remain unchanged. Rewriting
  replaces direct references by identity and introduces no arithmetic, casts,
  truncation, latency or two-state assumptions.

The public regression includes ordinary untagged aliases, renamed unrelated
components, default/explicit enable/opt-out, repeat emission, symbolic widths,
protected and otherwise ineligible cases. Existing standalone pass, common FIFO
proof, mutation and inherited source-integrity coverage is retained.

The source overlay is renewed through the existing source-commit/manifest-seal
mechanism. Its immutable baseline, normalized checker hash, exact governed
inventory, modes, byte hashes and HEAD/index/worktree checks remain active.

## Actual public-path example

Excerpt from `OrdinaryNamedAliasTopology`, generated by
`MorphVerilog(config) { new ProductionNamedAliases(width) }` with
`HdlInt.param("WIDTH", default = 8, min = 1, max = 16)`:

```scala
val bitSource = Bits(width bits)
bitSource := a ^ b
val bitCloneAlias = cloneOf(bitSource)
bitCloneAlias := bitSource
clonedResult := bitCloneAlias

val flagSource = Bool()
flagSource := choose === a(0)
val flagAlias = Bool()
flagAlias := flagSource
flagResult := flagAlias
```

Actual generated Verilog excerpts with explicit opt-out:

```verilog
  wire       [WIDTH-1:0]    bitSource;
  wire       [WIDTH-1:0]    bitCloneAlias;
  wire                flagSource;
  wire                flagAlias;
  assign bitSource = (a ^ b);
  assign bitCloneAlias = bitSource;
  assign clonedResult = bitCloneAlias;
  assign flagSource = (choose == a[0]);
  assign flagAlias = flagSource;
  assign flagResult = flagAlias;
```

Actual generated excerpts with default-on (identical to explicit enable):

```verilog
  wire       [WIDTH-1:0]    bitSource;
  wire                flagSource;
  assign bitSource = (a ^ b);
  assign clonedResult = bitSource;
  assign flagSource = (choose == a[0]);
  assign flagResult = flagSource;
```

The full modules retain the `WIDTH` parameter. No user tag or additional pass
flag appears in this source. The same topology in `UnrelatedPacketRouter`
produces the same transformation after normalizing only the component name.

## Actual exclusion audit

Read-only inspection of the native proof on the public fixture confirms:

| Declaration | Result |
| --- | --- |
| `bitCloneAlias`, `flagAlias`, `signedCloneAlias`, `unsignedCloneAlias` | Eligible; removed |
| `bitAlias` | `WA05-NATIVE-PACKED-TYPE`: separate symbolic width identity |
| `signedAlias`, `unsignedAlias` | `WA05-NATIVE-SOURCE-SCOPE`: direct port source |
| `keptAlias`, `guardedAlias` | `WA05-NATIVE-PRESERVATION` |
| `sampledAlias`, `conditionalAlias`, `rootProceduralAlias` | `WA05-NATIVE-USE-CONTEXT` |
| `softResetAlias` | `WA05-NATIVE-CLOCK-DOMAIN` |
| `timingAlias` | `WA05-NATIVE-REFERENCED-METADATA`: false-path source reference |
| `toChildAlias` | `WA05-NATIVE-USE-CONTEXT`: child input receiver |
| `fromChildAlias` | `WA05-NATIVE-SOURCE-BOUNDARY` |
| `removableAlias` | Not a source-named candidate (`Nameable.REMOVABLE`) |

Separate fixtures retain aliases under assignment line-comment metadata and
opaque external metadata. `MorphVerilog` still rejects its unsupported
`genLineComments` mode; the comment-preservation fixture uses the existing
public `SpinalVerilog(MorphWireAssignmentPasses(config))` entry point.

## Timing-generator reproduction

The available display-controller snapshot contains an older, unchanged
`DisplayControllerProgressiveTimingGenerator.scala` (SHA-256
`cfefbaa663188669ed741a33fdda0a7febb5974e9c80f2bc7057876f5bd36af7`). Its
generator uses native fixed-width generation and contains no retained
MorphHDL port-parameter metadata. It is not the later parameterized generator
reported by the user: current `MorphVerilog` correctly rejects this old source
with `SPINAL-PARAMETERIZED-VERILOG-UNTAGGED-PORT`.

The source was left unchanged and exercised in an isolated harness through
the supported public `SpinalVerilog(MorphWireAssignmentPasses(config))`
handoff for PPC 1 and 4. Both default/explicit-on outputs agreed, all three
modes repeated identically, six strict Verilog-2001 compilations passed, and
both on/off sequential equivalence proofs passed (`async2sync`,
`equiv_simple`, `equiv_induct -seq 6`, `equiv_status -assert`). These are
concrete old-snapshot checks, not qualification of the unavailable later
parameterized display-controller source.

| Surviving wire category in the inspected timing source | Actual reason |
| --- | --- |
| `timing_laneX_0` | `WA05-NATIVE-USE-CONTEXT`: root default feeds a multiply assigned destination emitted in `always @(*)` |
| `timing_laneY_0` | `WA05-NATIVE-USE-CONTEXT`: procedural receiver and nested conditional read |
| Remaining lane X/Y elements | Multiple/default-plus-conditional drivers; not single direct alias candidates |
| Totals, legality, alignment, group/ready/accept expressions | Expression/type-node or literal drivers; not direct named aliases |
| Ports and timing registers | Declaration-kind exclusions |

No eligible ordinary named alias remains in this inspected old snapshot.
There is no source-name/component-name exception for it in the compiler.

## Required qualification

The existing workflow runs both Scala 2.12.18 and 2.13.12 lanes and compares all
21 production/reference/debug outputs between Scala versions. Each lane checks
repeat byte identity, public default/explicit-on agreement, opt-out behavior,
four actual alias removals per ordinary fixture, thirteen surviving aliases,
strict Verilog-2001 compilation, lint and synthesis. The ordinary fixtures add
32 width/component equivalence cases (four-step SAT), 2,048 four-state cases
and two rejected functional mutations to the existing generic/FIFO checks.

The separate pass workflow retains all historical proof legs and the common
FIFO reference over all 512 `WIDTH=1..64`, `DEPTH=1..8` bindings. Its 16 shards
run twice and require the existing 9,216 equivalence and 9,216 reachability
results. No proof domain, mutation control, inherited workflow or source
integrity check is removed or changed to an allowed failure. The PR must pass
the applicable gates on its final commit before merge.

Local qualification passed both Scala lanes: 22 canonical/public-handoff tests
per lane, 144 standalone pass tests per lane, all 21 cross-Scala byte comparisons,
the production strict-tool/four-state/equivalence/mutation checks above, and
146 existing proof-harness unit tests. Restoring the `39d888874` named phase in
an isolated classpath causes the unchanged public fixture to fail with
`public production path removed no named alias`.

The inherited gates also exposed a projection-composition defect in the
previous default-on source overlay: it could resurrect a production path
already removed by a verified predecessor projection. The repair distinguishes
that case from a historical change genuinely canceled by the current bytes
using the real revision-to-HEAD inventory. Complete byte/source verification
is unchanged. Added regression cases cover overlap inclusion/exclusion,
cancellation restoration, unrelated-path preservation and production-only
inventory scope; all existing live source/Git mutation controls remain active.

# Executable architecture fixtures

These files are expected-output contracts for the future parameterized backend;
they are not claimed to be generated by Increment 1.

- `parameterized_wire.v` proves a symbolic packed width and external parameter
  override without regenerating the module.
- `lane_array.v` proves child parameter forwarding, one logical child module,
  a named generate-for loop and parameterized indexed part-selects.
- The matching testbenches instantiate both defaults and awkward overrides
  (`WIDTH=13`, `LANES=3`, `DATA_WIDTH=5`).

Run:

```bash
./morphhdl/scripts/check-contracts.sh --require-tools
```

The required mode needs Icarus Verilog, `vvp` and Yosys. Without the flag, the
script still performs structural and forbidden-SystemVerilog checks and reports
missing external tools as skipped.

Increment 2 must emit the parameterized-wire shape from ParamRTL and compare it
with this contract. Later increments take ownership of the lane-array fixture as
hierarchy and generate support are implemented.

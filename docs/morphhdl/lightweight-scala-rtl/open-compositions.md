# Open lightweight compositions

These are current development findings, not reopened historical CA claims.
No application source or compiler pin has changed.

## Literal-depth parent Vec to generic child Vec (LWR-08)

The literal-depth connection is now repaired in development. An opaque native
receipt authenticates the exact direct parent/child pair, formal substitution,
logical geometry, audit-only padding and every driver consumed at publication.
The 11-suite hierarchy regression passes 194 tests on each supported Scala
version; evidence is recorded in `progress.json`. Remote qualification is pending.

The supported adaptation covers root-scope, scalar-element Vec boundaries with
pure input or output directions. Differing nested physical capacities,
mixed-direction records and branch-local adaptation are not claimed. Equal
capacity paths keep their existing behavior. Negative tests revoke authorization
for changed padding values/widths, poison, missing/competing writes and consumed
extra output lanes.

## Hardware-selected row with scoped column writes (LWR-04/05)

The new development fixture exposed writes landing on a dynamic read-view alias
rather than the owning array. The current repair preserves the original scoped
alias and native conditions, creates complete next-row storage, and forwards the
row through exact native decoded-write identities. Publication authenticates the
whole-row assignment and each terminal scalar edge before combining them.
Procedural aliases also propagate their storage requirement to the array.

Four original shorthand and four explicitly normalized controls pass local
Scala 2.12 and 2.13 generation, four-state simulation, lint, synthesis and independent SAT
checks in both layouts. The hardened run also passes 12 ownership/mutation
rejection tests. Independent forwarding journals and explicit native driver
bridges are implemented. Broader affected regressions remain in progress; this is not a completed roadmap phase or remote qualification.

The initial admission covers one module-owned complete unit-stride column loop
into a combinational scalar-element row, with one exact whole-array default.
Missing defaults, competing writes, read-only target views, feedback and changed
transformation edges are rejected. Partial rows, multiple independently captured
write aliases, register destinations and structurally nested decoded-write loops
are not claimed by this repair.
